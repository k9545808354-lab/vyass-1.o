# Vyas Timetable (Android)

Android Kotlin & Jetpack Compose rewrite of the **SSBT's COET Jalgaon — First Year Computer Engineering** timetable, unit notes PDF hub, and PPS C programming compiler suite.

## Core Features

- **Security Lock Screen**: Access verification (`SSBTCOMP`) with error feedback.
- **Biometric Gate & C Kernel Animations**: Custom Jetpack Compose Canvas animated Teddy Bear unlocking the biometric vault door, followed by a line-by-line C compilation terminal sequence (with instant Skip support).
- **Class Division Selection**: Divisions **E** (Room 230), **F** (Room 234), and **G** (Room 236).
- **Official Weekly Timetables (MON–SAT)**: Interactive horizontal-scrollable grid with faculty codes, batch splits (`E1–E3`, `F1–F3`, `G1–G3`), lunch break column, Guardian Hour (`TGS`), and clickable subject tags.
- **Subject Units (1 to 5)**: Per-subject unit directory with a dedicated **Dual Dark C Compilers (IDE)** launcher for **PPS**.
- **Dual Dark C Compilers**: Tabbed OneCompiler & JDoodle dark-mode C11/C17 WebViews, one-tap Lab Snippets (Hello World, Prime Check, Factorial, Fibonacci) copied to clipboard, and fullscreen browser launch.
- **PDF Notes Hub & In-App Reader**: Pre-bundled Unit 1 PDFs, zero-permission Storage Access Framework PDF upload (`OpenDocument`) persisted locally, SAF export (`CreateDocument`), and native `PdfRenderer` multi-page viewer with external app launch via `FileProvider`.
